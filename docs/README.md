# 旅行記録アプリの仕様

## 現在の状態

対話で仕様と技術構成を整理中。アプリの実装・依存のインストールは未開始。実装開始にはユーザーの明示的な許可が必要。HTMLモックは承認済みの画面検討用資料で、実データの保存機能は持たない。

MVPは、木製の地図に訪問済みのピンを留め、県・国ごとの訪問履歴から写真と日記を振り返る個人用モバイルアプリ。日本・世界の両方を含め、バックアップ・機種変更時の引き継ぎは将来候補とする。

## 状態の読み分け

- 決定事項・確認済み：ユーザーと合意した方針。
- 暫定・第一候補：評価や検証を前提にした方針。検証済みとは扱わない。
- 設計案・検討中・未決定：未確定。既存の決定事項と同じ扱いにしない。
- [将来のバックアップの保留資料](future-backup.md)：過去の検討の退避先。MVPの要件や依存関係ではない。

## 実装前・実装時に具体化する主な点

- 規則的な見た目を避ける写真の自動配置、変化の範囲・安定性・調整方法。
- 地図データの正式な採用、加工、195か国との対応、小さな場所の選択性。
- DBの列・制約・移行、ファイル保存・削除と途中終了からの回復手順。
- 依存バージョンの最終確定と、ネイティブ・ブラウザStorybookの組み合わせの検証。
- JPEGの圧縮品質、透明部分の変換、性能の受け入れ基準。
- チュートリアルの画面構成と、地図の読み上げ操作の対応範囲。

残件があるため、現時点で仕様全体を確定済み・実装準備完了とは扱わない。機能や技術の方針変更時は、関連文書とモックの整合性を更新する。
