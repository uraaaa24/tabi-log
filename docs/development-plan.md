# MVPの開発順

## 状態

進め方は確認済み。ユーザーの許可を受け、段階1のExpo・共通部品・ブラウザStorybook・React Compilerを構築した。実機・ネイティブ検証などの残件は[開発手順](development.md)を参照。段階2以降の製品機能は未着手。

## 決定した順番

1. 開発環境とハーネスを整える。採用したpnpm・Oxlint・Oxfmt・Vitest・Storybook・Lefthook・GitHub Actionsを共通の検証手順でつなぎ、Codex cloudでも作業できる環境を目指す。
2. 日本地図で「場所を選ぶ → 記録する → アルバムで振り返る」を一通りつなぐ。端末内への記録・写真の保存と再表示を含め、中心の体験を確認する。
3. 世界地図にも広げる。国単位の訪問状態・履歴と日本の都道府県の関係を、決定済みのルールに沿って実現する。
4. 木目・ピン・スクラップの質感と、保存の安定性を仕上げる。iPhone実機・Androidエミュレーターに加え、公開前にAndroid実機でも主要操作を確認する。

世界地図もMVPの範囲に含める。段階2だけでMVP完成とはしない。保存の安全性は初めから設計し、段階4では途中終了や実データ量を想定した確認・改善を行う。バックアップは全段階を通じてMVP対象外。
