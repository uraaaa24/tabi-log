# HTML画面モック

「休日のスクラップ」を採用方向とするHTMLモック。他のデザイン案と比較専用ページは削除し、このフォルダに必要な画面と素材をまとめた。

## 見方

[地図のモック](index.html)をブラウザで開く。インストールや外部通信は不要。PCでは左に画面切り替え、右にスマートフォンの画面案が表示される。木目・紙・マスキングテープの表現は全画面共通。スマートフォンでは上部に画面切り替えが並ぶ。

| 画面 | ファイル | 確認する内容 |
| --- | --- | --- |
| 地図 | [index.html](index.html) | 木目、薄茶の地形、立体的な画鋲、日本・世界の切り替え |
| 場所の履歴 | [place.html](place.html) | 訪問状態、年ごとの履歴、日付とサムネイル、追加への導線 |
| 訪問アルバム | [album.html](album.html) | 紙、テープ、軽い傾き、写真から日記へ読む流れ |
| 入力・編集 | [edit.html](edit.html) | 日付から始めるフォーム、写真、自由文、交通手段 |
| 写真一覧 | [photos.html](photos.html) | 縦横比の異なる写真を、重ねずテープで貼った表現 |
| 設定 | [settings.html](settings.html) | 使い方・端末内保存の説明、チュートリアルの入口 |

## 位置づけ

- アプリ実装ではなく、対話で確認するための画面案。既存の[仕様](../map-experience.md)を基にしているが、ボタン配置、余白、色、具体的な素材は未確定の提案。写真プレビューは先頭2枚までとする方針を確認済み。
- 「旅の記録」は仮の表示名。長野県・日付・文章・訪問状態は架空のサンプル。
- 写真は、このモック用のSVG風景イラスト。実際の写真に置き換えた場合の見え方は別途確認する必要がある。
- 地図は表示イメージを示す仮の図。都道府県境・国境は正確ではなく、47都道府県・195の国を網羅していない。日本地図の選択は長野県の画面例に接続する。世界地図は表示例のみ。
- 紙と木目の質感はCSSで表現している。採用する完成素材を確定したものではない。

## 試せる操作

- 六つの画面間の移動。地図から長野県、履歴からアルバム、編集や写真一覧への移動。
- 日本・世界の地図表示切り替え。検索フォームと場所一覧は設けない。
- ピンを外す確認と、この画面内だけの空表示への切り替え。ページを開き直すと元に戻る。
- 写真を選んで大きく開く、前後へ移動する。モックの拡大表示はダイアログで、製品版の全画面・ピンチ拡大を再現したものではない。
- 複数日の入力欄の表示切り替え、交通手段の複数選択、必須日付の確認。保存を押すとサンプルのアルバムへ進む。
- 設定画面の各操作は説明ダイアログを表示する。

実データの保存、写真の取り込み、地図の拡大縮小、未保存変更の確認、初回チュートリアルは、この六画面のモックには実装していない。これらの既存仕様を削除する意味ではない。

## 確認状況

ローカルの参照ファイルとHTML・JavaScriptの構成を確認。実ブラウザでの画面撮影は、この環境でChromeが起動終了したため未確認。

訪問済みの場所はピンだけで表示する。着色と比較ボタンは、MVPに着色を含めない決定に合わせて削除済み。

アルバムの「編集」から開いた場合のみ、フォーム末尾に訪問記録の削除操作を表示する。確認後はサンプルの訪問履歴へ移る。新規登録では削除操作を表示しない。実データの削除・保存は行わない。

バックアップ・機種変更時の引き継ぎはMVP対象外へ変更したため、設定モックから関連操作・案内を削除した。チュートリアルの画面数は再検討する。

## 写真配置の試作

アルバムと写真一覧を、横長は大きめ・縦長は小さめを目安に、幅・位置・傾き・余白へ変化を付ける案に更新した。全体は2列程度とし、2：1・1：1などの比率は固定しない。写真全体を表示し、番号・全画面表示は追加順とする。

写真一覧のアプリ画面外にある検証用操作で、横長中心・縦長中心・混在を切り替え、追加・先頭削除・開き直しを確認できる。これらの検証用操作は製品UIではない。

モックでは写真IDを基準に幅の希望値・傾き・位置の小さなずれ・余白を決め、周囲に収まる幅を割り当てて保持する。回転後の外枠が重ならない位置へ上から詰める。再表示で再抽選はせず、削除後も残った幅・傾きを保つ。末尾が1枚だったところに追加する場合は、その末尾写真の幅も局所的に調整する試案。可変幅のため空白が残る場合があり、許容範囲・実アプリのアルゴリズム・仮想化方式は未確定。

実データの保存はしないため、ブラウザの再読み込みではサンプルの初期状態に戻る。実ブラウザでの見た目はこの環境では未確認。
