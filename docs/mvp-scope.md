# MVPの範囲

## 決定事項

- バックアップ・復元・機種変更時の引き継ぎはMVPに含めない。端末変更や紛失時の記録引き継ぎは保証しない。

- 最初に使える版（MVP）に、日本の都道府県と海外の国の両方を含める。
- 日本地図と世界地図の切り替えを含める。
- 日本と海外のどちらも、場所ごとの「行った／行っていない」と、場所を選んで訪問記録を振り返る体験の対象にする。
- 海外の訪問先は国単位とし、国以外の地域を独立した訪問先にはしない。
- 世界地図では、MVPから国連加盟国193とオブザーバー国2の計195を訪問先として選べるようにする。
- モバイルアプリとして提供する。MVPは一台のスマートフォンでの利用を想定し、複数端末で同じ記録を見る機能は求めない。
- iPhoneとAndroidの両方に対応する。
- MVPの画面表示は日本語のみとする。
- MVPはストアで一般公開する。公開直後は宣伝せず、少人数に使われることを想定する。
- MVPのストア公開地域は日本とする。世界地図で記録できる国の範囲には影響しない。
- iPhone版とAndroid版は、両方の準備が整ってから同じ時期に一般公開する。
- 公開に固定の期限は設けず、記録・写真の保存と振り返りの品質を確認してから公開する。
- MVPは無料・広告なしで公開する。将来の費用回収方法は未決定。
- 旧端末を紛失・故障して操作できない場合の記録と写真の復元は、MVPでは必須にしない。
- MVPではアカウント登録を不要とし、記録と写真は端末内に保存する。
- 地図に訪問済みの県数・国数のカウントは表示しない。
- 他人に地図・訪問記録を共有する機能は設けない。将来も個人用の記録として扱う。
- アプリ起動時に、端末のロックとは別の認証は求めない。
- 訪問記録に追加した写真はアプリ内にコピーする。
- 写真は振り返りに適した画質で保存する。元画像と同じ画質での復元・書き出しはMVPの要件としない。
- 訪問記録ごとの写真枚数に、小さな固定上限は設けない。
- 訪問記録内の写真は追加順に表示する。
- 初回チュートリアルで地図・記録の使い方と端末内保存を案内する。バックアップ操作の案内は含めない。
- 通信がない状態でも地図を見られ、訪問記録の閲覧・追加・編集ができるようにする。
- 場所の検索フォーム・補助の場所一覧は設けない。小さな県・国は地図を拡大して選ぶ。
- 日記・メモの文章を対象とした訪問記録の検索はMVPに含めない。
- 場所をまたいだ全訪問記録の一覧はMVPに含めない。県・国ごとの訪問履歴から振り返る。
- 訪問記録には日付・期間、複数写真、日記・メモ、複数の交通手段を含める。日付・期間以外は任意入力とする。
- 保存後の訪問記録では、日付・期間、日記・メモ、交通手段、写真をすべて編集できる。
- 写真は訪問記録から1枚ずつ削除できる。
- 写真を削除する前に確認を表示する。
- 訪問記録を1件ずつ削除できる。場所のピンと他の訪問記録は残す。
- 訪問記録の削除前に確認を表示する。
- 写真はスマートフォンの写真アプリから選んで追加する。アプリ内の撮影機能はMVPに含めない。
- 写真は一度に複数枚を選んで追加できる。
- 訪問日・期間は手で入力する。写真の撮影日時から候補を出す機能はMVPに含めない。
- 訪問先の県・国は利用者が手動で選ぶ。GPSや写真の位置情報による自動判定はMVPに含めない。

## 検討中の事項

- 将来の収益化方式。将来お金をいただく場合の主目的は開発・維持費をまかなうこと。買い切り・サブスクリプションなどの採否は未決定。
- 将来有料機能を設ける場合の、iPhoneとAndroid間の購入状態の扱い。
- 写真の具体的な表示品質と容量。
- 訪問記録の登録・編集・削除、写真の管理の詳細。

## 将来候補（未決定）

- バックアップ・復元・機種変更時の引き継ぎ。以前の詳細検討は[保留資料](future-backup.md)を参照。

- 訪問済みの県・国への着色。MVPには含めない。追加する場合は既定色を設け、アプリに合う用意済みの色から変更できる方式とする。具体的な色と設定の適用単位は未決定。

- アプリ終了後の未保存の下書きの復元。
- 都市単位での海外訪問記録。
- 複数の場所を一回の旅行として束ねる機能。
- 訪問記録内の写真を利用者が自由に並べ替える機能。
- 写真の撮影日時を使った訪問日・期間の入力補助。
