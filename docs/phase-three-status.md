# Phase3：世界地図

## 実装範囲

段階3の「世界地図にも広げる」を実装。国単位の訪問状態・記録・振り返りと、日本の都道府県との関係を、[訪問記録モデル](record-model.md)と[地図の体験](map-experience.md)の決定に沿ってつないだ。質感の最終調整・保存の安定性の確認・初回チュートリアル・公開前の実機受け入れは後続段階。MVP全体の完成・ストア公開準備完了を意味しない。

- 国連加盟国193とオブザーバー国2の計195か国を選べる、木のボード上の平面の世界地図（ミラー図法・太平洋中心）。データと加工は[地図データ](map-data.md#phase3の世界地図データ)を参照。
- 地図ボード左上の「日本」「世界」の切り替え。両方の地図を表示中は保持し、切り替えて戻っても拡大率と位置を保つ。前回の地図は `app_settings` に保存し、次回起動時に開く。初回は日本地図。
- 世界地図は1〜20倍。縦長の画面で細い帯にならないよう、画面の高さいっぱいまで拡大して日本の周りを中央に開く。指で縮めれば全体表示に戻る。ピンとチェキは開いた時の拡大率で原寸とし、日本地図での縮み方を変えていない。
- 最大20倍でも押せない30か国には丸い木の選択駒を置く。地域・属領（台湾・コソボ・西サハラ・香港・グリーンランドなど）は形だけ表示し、押しても反応しない。南極は描かない。
- 国を選ぶと県と同じ流れで、記録がなければ入力画面、あれば旅の一覧を開く。国の記録・写真・ピンの保存、ピンだけの登録、場所ごとの削除は県と同じ処理を使う。
- 世界地図の日本は、訪問済みの県が1つ以上あればピンを持ち、全都道府県で最新の写真付きの旅の先頭写真を吊るす。日本を押すと日本地図へ移る。日本全体の訪問状態・記録は保存しない。
- 訪れた県数・国数は表示しない。MVPの範囲の決定に反してPhase2の日本地図に残っていた「N / 47」も外した。E2Eは地図の切り替えの選択状態で表示中の地図を、読み上げの「訪問済み」の数で訪問数を確認する。Androidの起動画面検査も「訪れた場所」の代わりに「日本地図」の文字で製品画面を判定する。
- 日本・世界とも地形の影をなくし、板に貼り付いた見た目にした。世界地図の境界線は日本地図と同じ太さ1の丸い接合。
- 旅の一覧・入力画面ではシルエットの下に、アルバムでは訪問期間の上に、県名・国名を表示する。国のシルエットは遠くの小さな領土を除いた主な陸地に合わせる。
- 設定の「地図について」に世界地図の出典（Natural Earth）と加工内容を追加した。

既存の端末の記録は、起動時に国が `places` へ追加されるだけで変更しない（スキーマの版は1のまま）。

## Phase3で決めたこと（2026-11-18、ユーザー確認）

- 世界地図は太平洋中心。平面の長方形の地図とし、外周が丸い図法は使わない。
- 小さな国は、世界地図だけ最大20倍に広げたうえで丸い選択駒で選ぶ。
- 195か国以外の地域は形を表示して押せない。南極は描かない。押しても案内は出さず、設定の「地図について」の説明で伝える。
- 世界地図は全体表示ではなく、ある程度拡大した状態で開く。
- 地図に影は付けない（日本・世界とも）。境界線は日本地図の線を基準に、太さ1で揃える。
- 県・国を選んだ後の画面には名前を文字で出す。
- 地図に訪問数は出さない（MVPの範囲の決定を維持し、日本地図の既存表示も外す）。

## 検証

- `pnpm check`：26ファイル・243テスト成功。世界地図データ（195か国・固定ID・地域の除外・ピンの内包・国境の共有・小国の判定・配置・表示枠）、生成処理（切れ目の反対側の小島の除去、選べない陸地の分離、checksum拒否）、国の追加でPhase2の記録を変えないこと、世界地図の日本のピン写真、前回の地図の保存、拡大した最初の表示の計算を含む。
- `pnpm build-storybook`：成功。`pnpm check:native-bundles`：製品・StorybookのiOS/Androidとも成功。
- ブラウザStorybook（Playwright・Chromium）：地図の切り替え・小国の駒・世界地図・場所の見出し・地図ボード（世界・320px幅・全訪問・切り替え）を表示して確認。ブラジル・オーストラリア・日本の形とバチカンの駒の選択、切り替えの選択状態、世界地図で日本のピンを押すと日本地図へ移ることを確認した。
- ブラウザE2E：48件成功（macOS、ローカル）。追加した `e2e/world.spec.ts` の6件（国の記録とピン・数、県から日本のピンと日本地図への移動、小国の駒からの記録、地域が選べないこと、前回の地図の再起動後の復元、拡大した最初の表示）は3回繰り返して成功。

- CI：[PR #5のrun](https://github.com/uraaaa24/tabi-log/actions/runs/44178966438)で check・commitlint・e2e・native-bundles・storybook、[Androidのrun](https://github.com/uraaaa24/tabi-log/actions/runs/44178966441)で android-smoke（Development Buildのコンパイルとエミュレーター上の製品・Storybookの起動画面検査）が成功。世界地図の操作・記録の受け入れ確認は含まない。
