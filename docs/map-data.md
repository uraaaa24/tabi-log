# Phase2の日本地図データ

出典：**地球地図日本（国土地理院）**。GeoJSONへの変換・都道府県名とIDの付与：**dataofjapan/land**。

- 配布元：[dataofjapan/land](https://github.com/dataofjapan/land)
- 使用ファイル：[japan.geojson（固定コミット）](https://github.com/dataofjapan/land/blob/c686f194db009794b63b38585af060fbe1b0b304/japan.geojson)
- 元データ：[地球地図日本](https://www.gsi.go.jp/kankyochiri/gm_jpn.html)
- [配布元の利用条件・出典説明](https://github.com/dataofjapan/land/blob/c686f194db009794b63b38585af060fbe1b0b304/README.md)

配布元の説明は、非営利目的で出典の明記、営利目的では出典の明記に加え著作権者への利用報告を求めている。アプリ内は地図右上の設定から開く「地図について」に出典・加工表示・原典と利用条件へのリンクを載せる。地図面には表記を重ねない。**営利目的で配布する前に利用報告と当時の原典の条件を確認する**。Natural Earthや国土数値情報2026年版を採用したという意味ではない。

元GeoJSONのSHA256：`b2fa31a9ce37c006904a06b8afcaeaf5ceeff40ae365eca167e09fbfff052f00`。

加工は `scripts/build/japan-map.ts`。固定した元データをSVG用の座標へ線形投影し、開発用の `mapshaper 0.7.101` で47県を一緒に簡略化する。隣県の共有境界を同じ線として処理し、県ごとに別々に間引いて隙間ができることを避ける。

- 微小なずれを0.01単位で揃え、0.02単位より狭い隙間を補正する。
- Ramer–Douglas–Peucker法の許容距離1.5（SVG座標単位）で細かな凹凸を減らす。交差の修復と各県の形状保持を有効にする。
- 簡略化で消える小島と面積4未満の小さな島は表示しない。元データの全離島を忠実に描く用途ではなく、47県を選ぶ木製パーツの模式図とする。
- 元の約80,370頂点・1,158リングを、1,044頂点・76リングへ整理した。出力は約20KB。島だけの県も含めて47県を残す。
- ピンは簡略化した最大パーツの内側に計算し直す。海上や県外に落ちる頂点平均は使わない。
- `JP-01`〜`JP-47` と都道府県名は維持する。記録は固定IDに紐づくため、形状やピン位置の変更で保存済みデータを移動しない。

再生成は `pnpm install --frozen-lockfile` 後、固定コミットのGeoJSONを `work/japan.geojson` に取得し、`pnpm map:generate work/japan.geojson`、`pnpm format` を実行する。checksumが一致しない入力は拒否する。生成とテストはプロジェクトのNode・pnpmだけを使い、Pythonや外部通信を必要としない。mapshaperは開発依存で、アプリには生成済みのSVGパスのみを同梱する。

描画は外側のViewを引き伸ばさず、SVG内部の変換行列で拡大する。県境は丸い接合と拡大率に依存しない細線を使い、拡大時も線幅とベクターの輪郭を保つ。

47県の存在・固定ID・頂点数の上限・ピンの内包・隣県の境界共有をテストする。生成処理にも人工的な凹凸を持つ隣接県と小島を入力し、境界の一致と県の保持を検査する。模式図は正確な境界の確認やナビゲーションには使わない。小さな県の実機での選択性、読み上げの到達性は引き続き確認する。
