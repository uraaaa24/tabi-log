# Phase2の日本地図データ

出典：**地球地図日本（国土地理院）**。GeoJSONへの変換・都道府県名とIDの付与：**dataofjapan/land**。

- 配布元：[dataofjapan/land](https://github.com/dataofjapan/land)
- 使用ファイル：[japan.geojson（固定コミット）](https://github.com/dataofjapan/land/blob/c686f194db009794b63b38585af060fbe1b0b304/japan.geojson)
- 元データ：[地球地図日本](https://www.gsi.go.jp/kankyochiri/gm_jpn.html)
- [配布元の利用条件・出典説明](https://github.com/dataofjapan/land/blob/c686f194db009794b63b38585af060fbe1b0b304/README.md)

配布元の説明は、非営利目的で出典の明記、営利目的では出典の明記に加え著作権者への利用報告を求めている。アプリ内は地図右上の設定から開く「地図について」に出典・加工表示・原典と利用条件へのリンクを載せる。地図面には表記を重ねない。**営利目的で配布する前に利用報告と当時の原典の条件を確認する**。Natural Earthや国土数値情報2026年版を採用したという意味ではない。

元GeoJSONのSHA256：`b2fa31a9ce37c006904a06b8afcaeaf5ceeff40ae365eca167e09fbfff052f00`。

加工は `scripts/build/japan-map.ts`。固定した元データをSVG用の座標へ線形投影し、開発用の `mapshaper 0.7.101` で47県を一緒に簡略化する。隣県の共有境界を同じ線として処理し、県ごとに別々に間引いて隙間ができることを避ける。

- 微小なずれを0.01単位で揃え、0.02単位より狭い隙間を補正する。
- 簡略化前に、面積4未満の微小な島だけを整理する。各県の最大パーツは必ず残し、主要な島は個別のパーツへ分けてから形状保持付きで簡略化し、最後に県単位へ戻す。
- weighted Visvalingam法で大きな辺へ整理する。閾値は最大3.5、パーツの面積の平方根×0.14を上限とし、小さな島や県ほど弱く簡略化する。下北・能登・薩摩/大隅の特徴が消えないよう、青森・石川・鹿児島は最大2に抑える。
- 簡略化後の県の面積が、表示対象として残した元の陸地面積の80〜120%を外れる場合は生成を拒否する。島の位置の移動、県単独の拡大・回転、沖縄の別枠への移動は行わない。
- 元の約80,370頂点・1,158リングを、900頂点・85リングへ整理した。出力は約18KB。県境は大きな辺のままにし、宮古・石垣・西表、対馬・壱岐・五島、屋久・種子・奄美などの主要な島を残す。
- ピンは簡略化した最大パーツの内側に計算し直す。海上や県外に落ちる頂点平均は使わない。
- `JP-01`〜`JP-47` と都道府県名は維持する。記録は固定IDに紐づくため、形状やピン位置の変更で保存済みデータを移動しない。

再生成は `pnpm install --frozen-lockfile` 後、固定コミットのGeoJSONを `work/japan.geojson` に取得し、`pnpm map:generate work/japan.geojson`、`pnpm format` を実行する。輪郭と同時に `map-frame.json` を生成し、すべてのパーツの外接範囲に16単位の余白を付けて、全体表示の中央と拡大の基準にする。checksumが一致しない入力は拒否する。生成とテストはプロジェクトのNode・pnpmだけを使い、Pythonや外部通信を必要としない。mapshaperは開発依存で、アプリには生成済みのSVGパスのみを同梱する。

描画は外側のViewを引き伸ばさず、SVG内部の変換行列で拡大する。県境は丸い接合と拡大率に依存しない細線を使い、拡大時も線幅とベクターの輪郭を保つ。

47県の存在・固定ID・頂点数の上限・ピンの内包・隣県の境界共有・主要な島や半島の代表点の保持・全パーツが余白付き表示範囲に収まることをテストする。生成処理にも人工的な凹凸を持つ隣接県と小島を入力し、境界の一致と県の保持を検査する。模式図は正確な境界の確認やナビゲーションには使わない。小さな県の実機での選択性、読み上げの到達性は引き続き確認する。

見た目・操作・地理的な省略の再レビューは[地図ボードのレビュー記録](map-board-review.md)を参照。

# Phase3の世界地図データ

出典：**Natural Earth**（1:50m Admin 0 – Countries）。パブリックドメインで、利用・加工・商用配布に許可や出典表示は不要。アプリ内の「地図について」には「Made with Natural Earth」と加工内容を記載する。

- 配布元：[nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector)（v5.1.2以降の固定コミット `ca96624a56bd078437bca8184e78163e5039ad19`）
- 使用ファイル：`geojson/ne_50m_admin_0_countries.geojson`
- [利用条件](https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/LICENSE.md)

元GeoJSONのSHA256：`3e458fc036ad0a66411f2c1e6cac49c5d7bfb81cb1123bc513b22511a2b7fdeb`。50m版は195か国すべて（バチカン・ツバル・ナウルなど）を含む。

加工は `scripts/build/world-map.ts`、195か国の対応表は `scripts/build/world-countries.ts`。

- 国の対応：Natural EarthのADM0_A3から、記録用の固定ID（ISO 3166-1 alpha-2）と日本語の表示名へ対応付ける。北キプロス・ソマリランドは国連の認めるキプロス・ソマリアに含める。表にない地物（台湾・コソボ・西サハラ・香港・グリーンランドなど）は、選べない陸地として1本の輪郭にまとめる。南極は除く。
- 投影：mapshaperでミラー図法・中心経度150度（`+proj=mill +lon_0=150`）に投影し、全幅を約1,000単位の座標にする。大西洋（西経30度）で切れる。切れ目の反対側へ回った国の小島（アゾレス諸島の西端など）は、同じ国が地図の両端に分かれないよう省く。
- 簡略化：日本地図と同じく、共有する国境をまとめてweighted Visvalingam法で簡略化する（閾値は最大1.4、パーツの面積の平方根×0.12）。赤道付近で約800km²未満の島は、各国の最大パーツを除いて省く。面積4単位²以上の国は、元の面積の80〜120%を外れたら生成を拒否する。
- 約8,700頂点・出力約140KB。ピンは各国の最大パーツの内側に置く。最大パーツの外接範囲が2.5単位未満の30か国に `small` を付け、地図では丸い選択駒で選ぶ。
- 出力は `countries.json`（日本を含む195か国）、`world-land.json`（選べない陸地）、`world-frame.json`（16単位の余白付きの表示枠）。日本（`JP`）は世界地図の案内先で、記録は都道府県に紐づく。

再生成は、固定コミットのGeoJSONを `work/ne/ne_50m.geojson` に取得し、`pnpm map:world work/ne/ne_50m.geojson`、`pnpm format` を実行する。checksumが一致しない入力は拒否する。

195か国の存在・固定ID・地域が選べないこと・ピンの内包・隣国の国境共有・頂点数の上限・小国の判定・太平洋中心の配置・表示枠への収まりを `scripts/build/world-map.test.ts` で検査する。生成処理にも、切れ目の反対側の小島と選べない陸地を含む人工データを入力して検査する。
